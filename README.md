# MobiPics - 모비노기 스크린샷 자동 정리

![icon](./images/icon_256px.png)

[마비노기 모바일](https://mabinogimobile.nexon.com/) 스크린샷 자동 정리 유틸리티

![introduction](./images/introduce.png)

## 기능

- 실시간 스크린샷 모니터링 및 자동 정리
- 년-월 폴더 자동 생성 (예: 2025-08)
- 중복 파일 안전 처리 (해시 비교)
- 시스템 트레이 상주
- 시작 프로그램 등록 기능
- 커스텀 스크린샷 대상 폴더 경로 설정
- 대상 폴더 마커 파일 자동 생성 (MobiPics.txt)
- 자동 업데이트 확인

## 의존성 설치

```bash
pip install -r requirements.txt
```

## 실행 (개발 환경)
```bash
./run_dev.bat
```

## 빌드 (배포용 exe 생성)
```bash
./build.bat
```
